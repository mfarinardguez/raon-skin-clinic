# Raon Skin Clinic

## Descripción General

Raon Skin Clinic es una aplicación web que ayuda a las personas a encontrar productos de cuidado de la piel que realmente se adapten a su tipo de piel. A menudo, los productos de skincare prometen ser “para todo tipo de pieles”, pero en la práctica no lo son. Esta web permite:

✨ **Buscar productos** específicos de skincare.  
🧴 **Ver el tipo de piel recomendado** para cada producto (seca, grasa, mixta, sensible, etc.).  
💬 **Leer reviews** de otros usuarios que ya han probado los productos.  
⭐ **Ver ratings** para decidir qué productos son más confiables.

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/mfarinardguez/raon-skin-clinic.git

2. Instala dependencias:

    ```bash
    npm install

3. Ejecuta la aplicación:

    ```bash
    npm start

4. Abre en tu navegador:

    http://localhost:4000

## Tecnologías utilizadas
- **Angular**: Framework principal para la interfaz.
- **Firebase**: Base de datos, autenticación y hosting.
- **GraphQL**: API para consultas de productos.
- **CSS3**: Estilos y diseño de la web.
